# Instructions for AI assistants (Claude, Codex and others)

This repository holds small, independent games and creative experiments. It is not the iQ apps repository and has none of its release, signing or testing rules.

- **One folder per project.** Work only inside the folder for the project you were asked about. Do not change other projects' folders unless asked.
- **New project?** Create a new top-level folder with a short lowercase-hyphenated name, a `README.md` (what it is, how to play or run it, controls) and a row in the table in the root `README.md`.
- **Keep projects self-contained.** Prefer games that run in a browser from a single `index.html`. If a project needs tools or libraries, list them and the exact commands in its README.
- **Assets.** Small images, sounds and fonts a game needs may be committed in the project's folder. Do not commit videos, large generated files, model weights, caches or `node_modules`.
- **No secrets.** Never commit passwords, API keys, tokens or personal data.
- **British English** in text the player sees and in documentation.
- **Git.** Work on a branch named for the project and the change, and open a pull request unless the owner says to commit straight to `main`.
